# Les images de l'appli

## Photos des docteures
Déposez les photos ici, avec ces noms :
- `images/johana-lichaa.jpg`
- `images/clara-salem-melloul.jpg`

Une photo carrée, avec le visage au centre, donne le meilleur résultat. Ensuite, indiquez le chemin dans le champ `photo` du tableau `DOCS` de `index.html`. Tant que ce champ est vide, les initiales s'affichent.

## Personnages des vidéos : `images/personnages/`
Les fichiers `.svg` actuels sont des dessins provisoires. Le tableau `PERSOS` de `index.html` indique le fichier de chaque personnage : pour un nouveau dessin, déposez le fichier ici et changez son chemin dans `PERSOS`. Une image carrée sur fond transparent convient le mieux.
